Point an existing client at this server

Nothing else changes: same parameters, same responses. Replace https://api.2captcha.com with http://localhost:8000.

curl — classic form API

curl -s "http://localhost:8000/in.php" \
  -d "key=demo" -d "method=post" \
  -F "file=@captcha.png"
# → OK|248173905

curl -s "http://localhost:8000/res.php?key=demo&action=get&id=248173905"
# → OK|a7f3k     (or CAPCHA_NOT_READY while it is queued)

Python — JSON task API

import base64, requests, time

BASE = "http://localhost:8000"
body = base64.b64encode(open("captcha.png", "rb").read()).decode()

task = requests.post(f"{BASE}/createTask", json={
    "clientKey": "demo",
    "task": {"type": "ImageToTextTask", "body": body},
}).json()["taskId"]

while True:
    res = requests.post(f"{BASE}/getTaskResult",
                        json={"clientKey": "demo", "taskId": task}).json()
    if res["status"] == "ready":
        print(res["solution"]["text"]); break
    time.sleep(0.5)

One-liner helpers

# native one-shot endpoint: upload and get the text straight back
curl -s "http://localhost:8000/api/solve?key=demo&body=$(base64 -w0 captcha.png)"

# grab a generated test captcha with its ground-truth label
curl -s "http://localhost:8000/api/sample?length=5"

Teach it your captchas

Y-Solver queues captchas it failed, captchas it was unsure about, and a random slice of the rest. Type what you see and the model learns your renderer. Nothing leaves this machine, and the humans here are you and your team — never a crowd.

Train

When you have a few dozen labels:

python scripts/train.py --holdout 0.25

It trains, scores every engine on held-out samples, and only lets the learned model take over if it actually wins. The scoreboard is printed — read it before believing anything.

Honest scope

Y-Solver reads text-in-image captchas only. Interactive challenges (reCAPTCHA, hCaptcha, Turnstile, GeeTest…) are refused with ERROR_METHOD_NOT_SUPPORTED instead of pretending — see docs/scope.md. Nothing here bypasses a challenge that a script was never able to read in the first place.
